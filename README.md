# Depicture
### Описание
**Depicture** - приложение для изучения изобрательного искусства с помощью карточек

### Ключевой сценарий
Просмотр темы с соответствующими карточками

### Как запустить приложение
1. Создать проект на Unity (ver 6.02+)
2. Клонировать в корневую папку проекта репозиторий.
```bash
git clone https://github.com/name17less/Depicture
```

3. Запустить отладчик через Unity Editor

### Как воспроизвести сценарий
1. Запустить приложение
2. Выбрать одну из категорий по кнопкам вверху экрана
3. Выбрать предложению тему
4. Просмотреть карточки
5. Управление карточками через Next Card/Previous Card/Close
Информация о карточках получается через NetworkServicePlug (мок)
